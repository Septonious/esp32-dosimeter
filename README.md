This is a simple, yet very useful software for creating DIY dosimeters using a RadSens board. It was made for the ESP32C3 Super Mini board, however it may still work with other similar boards and MCUs. The internal values are set for the SBT-10A geiger counter, however you may still modify them for your own counters
